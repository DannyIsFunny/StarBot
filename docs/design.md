# 设计说明

## 目标

做一个体积小、结构简单、适合儿童把玩的机械风桌面机器人。首版先验证运动和控制，不加入复杂仿真或强化学习。

## 结构

底部使用木板或 PVC 板作为底盘，两侧安装带编码器的 TT 减速电机和轮子；ESP32-C3、MPU6050、驱动板和电池盒直接用螺丝、双面胶或扎带固定。

## 控制链路

```text
手机/电脑 -> ESP32-C3 -> TB6612FNG -> 两个直流减速电机
                         ^
                       MPU6050
```

## 边界

- 不兼容 D-BOT 的无刷电机和 FOC 固件。
- 不使用定制 PCB，采用开发板、洞洞板和杜邦线。
- AI 和强化学习属于后续扩展。
